## Generated structure

Run `python3 -B .logs/batch_G_gen/generate.py` from the repository root (the script also resolves paths from its own location). Free text lives in `content.py`, `requests.py` and `documents.py`; calendar/ID/export logic is in `generate.py`; hidden labels are in `truth.py`. Seed: `70110342`.

The generator first builds the complete underlying work ledger, including unlisted events. It then picks uneven representative slots for employee prose. A shared 14-day sprint epoch, second-week completion bursts, variable monthly workload/leave factors and lower weekend probability control dates. Republic Day, Independence Day and Gandhi Jayanti are closed; this office calendar also closes Diwali 2025-10-20/21 and Holi 2026-03-04. These are calendar assumptions for this fictional employer, not a complete Indian holiday calendar.

All new authored PRs, unlisted PRs and review-target PRs receive numbers together after sorting by creation date per repository. Numbers remain within 2000–9000. All issues receive keys after sorting per allowed project. Neither allocation takes PID as a numeric input. Existing A–F PR/review numbers and ticket keys are reserved to prevent collisions. Linked tickets precede PR creation; assignee starts and resolutions are coherent. Jira request prose is separate from implementation PR text. Named reviewer corrections, open/closed states and role-appropriate diff sizes are included.

`monthly_activity` is reduced from this same ledger, including the listed records, rather than independently sampled totals. File counts are summed by actual merged month. GitHub history covers the full Kestrel tenure. CRM uses an explicitly declared recent closed-opportunity export window; its monthly totals cover every included created/closed month. The private ledger contains 1,515 authored PR events, 1,998 issue events and 1,437 reviews; bundles show 124 PRs and 159 issues. Nineteen authored PR creations are on weekends (1.25%); none on the declared holidays. A December 2022 Go PR may merge in January 2023; no Go PR is authored after the IC role and no Go merge activity extends beyond that carryover.

**Numbering boundary:** chronological allocation is global across Batch G, including all its unlisted records and reviews. Older bundles have pre-existing, mutually contradictory chronological numbering. New IDs avoid their collisions, but chronology across the combined A–G corpus cannot be made consistent while preserving the user’s prohibition on editing A–F. No older file is renumbered or repaired here.
