# Backend engineer hiring loop and rubric

## Loop (4 rounds, 3.5 hours total)
1. Recruiter screen (30 min)
2. Coding (60 min) - one problem, real-ish data, tests expected. We care that they run and test the code, not only the algorithm.
3. System design (60 min) - design a small payment retry service. Look for idempotency, failure modes, data model.
4. Hiring manager (45 min) - ownership examples, how they handled a production bug, how they disagree.

## Rubric (1-4 per signal)
- Problem solving, Code quality, Design, Ownership, Communication.
- Hire needs no signal below 2 and at least two at 3 or above for SDE-2.
- Do not hire on one strong signal. Write the evidence, not the adjective.

## Notes
Interviewers need the Interviewer Certification in Kestrel Learn. Debrief within 24h. The hiring manager decides, panel advises.
