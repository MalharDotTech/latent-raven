Before drain, check active exports and the oldest job age. A healthy API does not mean it is safe to evict the worker. The hook waits for the export gauge to reach zero, with an explicit timeout that aborts the change. It does not kill the export at the timeout. If it aborts, leave the remaining pool alone and record which job blocked the window.

For the rehearsal use a long-running export and a deliberately interrupted worker. Confirm that resuming the job does not publish a partial file. Check the gateway after restoring the worker: the first Pune drill missed this because pod readiness was green while the gateway still pointed at the old endpoint. That step is now before the final sign-off.

Terraform work is a separate change. Save the state serial and the old resource addresses before moving them. Review the plan from an existing workspace; an empty workspace cannot show a bad move. Stop if the plan destroys an existing production object unexpectedly. Platform partner reviews the address map before the apply.

Restore validation checks object hashes as well as counts. A missing manifest is a failed validation, not an empty successful comparison. The Python check now exits before producing a green summary in that case.
